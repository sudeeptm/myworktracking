# myworktracking

Prototype implementation for the **Personal + Team Work Journal** app.

## Quick Start

```bash
npm install
npm run dev
```

The Vite dev server runs on `http://localhost:4173`.

## What's Included

- Daily Journal capture flow with quick-add entry form
- Team tracker dashboard and weekly highlights
- Insights screen with filters, NL query, and evidence table
- Review builder with evidence list + export placeholders
- Prisma schema + docker compose for a Postgres database
